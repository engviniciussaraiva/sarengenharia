Permissões por módulo

Libere ou bloqueie cada módulo para o usuário. Ao liberar, o sistema concede acesso completo ao módulo.

Liberado O usuário pode acessar e utilizar integralmente o módulo. O sistema grava automaticamente visualizar, editar, excluir e administrar como verdadeiros.
Bloqueado O módulo não aparece para o usuário e nenhuma operação é permitida. As quatro permissões são gravadas como falsas.
Selecione um usuário para carregar as permissões.
